# Trabajo Práctico Integrador — Unidad 5

La entrega contiene dos proyectos independientes:

- `fastapi_backend/`: migración del Gestor de Productos del TP 4 a PostgreSQL con SQLModel.
- `tp-productos/`: pantalla estática de productos con React, TypeScript y Tailwind CSS.

La carpeta conserva únicamente los archivos necesarios para instalar, ejecutar y probar ambos proyectos. El TP 4 original permanece fuera de esta carpeta.

Consultá los README de cada proyecto para configurar el entorno. No incluyas `.env`, entornos virtuales, `node_modules` ni carpetas de compilación al comprimir la entrega.
